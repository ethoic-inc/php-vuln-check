# Getting help

- **A wrong result** (PATCHED, VULNERABLE or REVIEW looks wrong): open an issue with the *Wrong detection* template and paste the output of `php-vuln-check scan --format json`.
- **A question or an idea:** start a [Discussion](https://github.com/ethoic-inc/php-vuln-check/discussions).
- **A security problem in this tool:** use [private vulnerability reporting](https://github.com/ethoic-inc/php-vuln-check/security/advisories/new).
- **Anything else** (press, partnerships): hello@ethoic.com.
